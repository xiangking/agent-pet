# Asset Notice

This project includes built-in icons and pet sprites for local development and demonstration.

## Built-in Pet

- `pets/claude/` contains the bundled `Claude` pet used as the default built-in pet.
- Before publishing releases or distributing binaries, confirm that every built-in pet and brand-adjacent visual asset is either original work, properly licensed for redistribution, or replaced with a clearly redistributable alternative.

## Icons

- `icons/` contains the Tauri application icons generated for Agent Pet.
- `icons/icon.png` is the source icon image used to derive the platform-specific icon files.

## User Assets

User-provided pets should live in the app's user pet directory shown in Settings. User assets are not bundled into the repository unless explicitly added under `pets/`.
